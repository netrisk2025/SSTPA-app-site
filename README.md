## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production output is written to `dist/`. Vite copies public assets into the deployed static output, including:

- Methodology white paper: `public/files/SSTPA-Methodology-White-Paper-v14.docx`
- Earlier tools draft (archive): `public/files/SSTPA-Tools-White-Paper-v2.docx`

## Vercel deployment

This project includes `vercel.json` with:

- build command: `npm run build`
- output directory: `dist`
- framework: `vite`

After a Vercel personal access token is available, deploy from this directory with:

```bash
npx vercel --prod --yes --token "$VERCEL_TOKEN"
```

If this is the first deploy for the project, Vercel may need project linking metadata. The `.vercel/` directory is intentionally ignored and should be generated by the Vercel CLI.

**Do not deploy until Boss approves the revised marketing site.**
