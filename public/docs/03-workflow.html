Section 3 · Workflow V1

Methodology workflow (14 steps)

Authoritative execution sequence from Grok-Bot Workflow V1. Do not merge, split, or reorder these steps. Two control structures are part of the methodology: the Step 13 → Step 7 revision loop, and the Step 14 hierarchical recurse.

  1. Tier-1 architecture — Capability requirements → Tier-1 Systems and Connections. Tools: Requirements, Connection, Navigator, GUI.
  2. Allocate & join — Requirements onto Interface / Function / Element; join Interfaces to Connections. Tools: Requirements, Connection, Navigator, Flow (participates).
  3. Asset identification — Assets, Regime, Criticality, Assurance. Tool: Asset Manager.
  4. State behavior — States and transitions; VALID_IN edited in Context. Tools: State, Context.
  5. Environment & threats — Environments, valid States, reference threat research. Tools: Context, Reference.
  6. Hazard analysis — Hazards from the threat environment. Tools: Context, Reference.
  7. Functional Flow / STPA — Functional Flow and STPA Control Flow; feedback / process-model requirements. Tools: Flow, Requirements. Re-entry point from Step 13.
  8. Controls — Tailor Security Controls Baseline; map to SecurityControl; realizing requirements. Tools: Controls, Reference, GUI.
  9. Validation criteria — Satisfaction of Control “must” statements; Verification; Purpose-level Validation. Tools: Controls, Requirements, GUI.
  10. State-Trace — HOLDS / TRANSPORTS / USES matrix per Asset Assurance. Tool: Trace.
  11. Attacks — Actionable Attacks on susceptible entities. Tools: Attack, Reference.
  12. Loss / Attack Tree — Structured Attack Trees per Loss. Tool: Loss.
  13. GSN argument — Goal Keeper assurance case; if not credible, revise and return to Step 7. Tool: Goal Keeper.
  14. Hierarchical decompose — Element parents a child System; repeat Steps 1–13. See Decompose.
