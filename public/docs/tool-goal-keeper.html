Add-on Tool · Step 13

Goal Keeper Tool

Build the GSN (Goal Structuring Notation) assurance argument for each Asset Assurance. Solutions reference Validation, Verification, and Loss evidence. Validate for unsupported claims.

Revision loop

If the argument is not credible for the Regime: strengthen Countermeasures (Loss Tool), write countermeasure Requirements and Verification (Requirements Tool), then return to Step 7 (Flow) and refresh Controls → Trace → Attack → Loss as products change. Repeat until the GSN argument is acceptable.
